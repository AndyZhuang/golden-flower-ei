1.3 评估本身正在被证明不可信

  • 基准污染: 测试数据渗入训练集, 导致报告的 LLM 基准性能虚增 6%–40%
  • 有效寿命崩塌: 基准的有效寿命从数年骤降至 数月
  • 榜单 ≠ 生产表现: LiveBench 等未污染环境下, 前沿模型准确率比公开榜单 低 70%
  • 61.7% 的企业 AI 团队已采用程序化评估工具 (Braintrust / DeepEval) — 工具在, 但没有一个能评估「品性」
  • 现有玩家: LMArena (估值 $17亿), Artificial Analysis, Maxim AI, Adaline, Patronus AI — 全部评估「输出质量」, 没有一个评估「智能的品性」

三层互相饿养:XG 提供真实被评估对象 → Deqi 产出量表 → 量表 反过来指导 YS 的预训练目标。这是竞争者抄不走的飞轮。

2.1 Deqi — 大模型道德评估层框架

做什么:一层独立于模型之外的 道德评估层。输入: 模型输出 + 场景 + 价值量表。输出: 可审计的评估报告 + 置信度 + 依据链。

为何是「层」而不是「工具」:工具是被调用的, 层是模型必须经过的。Deqi 应当成为 agent 运行时的必经之路 — 类似 LLM 网关之于 API 流量。

2.2 XG — ME 方法论大模型

ME = Mechanism · Methodology · Emergence

层含义对应工程问题
Mechanism智能的内在机制 — 它如何从输入走到输出架构: 状态如何被表示、压缩、检索、遗忘
Methodology智能的方法论 — 它被教导与推理的秩序训练/后训练: 目标函数、数据配比、思维格式
Emergence智能的涌现 — 能力何时、如何出现评测: 如何证明能力存在, 以及它何时不存在

2.3 YS — 基座模型新范式

YS 不做「另一个基座模型」, 做「基座模型的方法论层」。

不训练基座模型, 而是产出: 可迁移的预训练配方、涌现的可验证指标、以及一套证明「模型品性可以在预训练阶段就被设计」的实验。

这个定位把 YS 从「需要 8-9 位数资本」变成「成本可控、风险低、但战略价值最高」的那一层。它不需要训练集群, 它需要的是「先定义标准的人」这个位置。

5. 执行策略

5.1 冷启动: 用 karma ledger 做数据飞轮

社区提交 question / translation / review → GFEI karma ledger (JSONL, 公开, 可审计) → 无污染的人类集体标注 → Deqi 量表校准 → 量表越准 → 客户越多 → 更多社区贡献

业界最缺的正是「高质量、未污染的人类数据」。而一个灵性/修行社区天然会产出高质量的、反思性的、诚实的标注 — 这正是道德评估需要的标注类型, 而普通标注众包平台产不出。这条飞轮是护城河, 不是营销话术。

招聘优先级: 评估科学负责人 > 合规 > ML 工程。理由:Deqi 是最先变现的, 而量表设计是它唯一的真护城河 — 必须由懂心理测量学的人主导, 不能外包。

组织原则

  1. 标准公开, 服务收费 — 核心量表与评测方法永久开源, 收入来自 API、审计与认证。标准一旦收费就失去中立性, 而中立性是唯一的信任来源。
  2. 可审计赢得可声称 — 每一个对外声明都必须有可追溯依据。
  3. 无污染数据优先 — 所有训练/评测数据必须记录来源与污染风险。
  4. 灵性不是修辞 — 「道德评估」必须有心理测量学基础, 否则只是情怀营销。
